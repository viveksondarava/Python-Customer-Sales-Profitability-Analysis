# \# Customer Sales \& Profitability Analysis — Python

# \## Project Overview

# 

# This project analyses customer sales and profitability data using Python to identify revenue performance, profit trends, regional performance, customer-segment behaviour and product performance.

# 

# The project demonstrates an end-to-end data analysis workflow using Python, from data loading and quality checks through business analysis and visualisation.

# 

# \## Business Objective

# 

# Analyse retail sales data to identify:

# 

# \- Revenue and profit performance

# \- Profitability by product category

# \- Regional sales and profit performance

# \- Customer-segment performance

# \- Monthly revenue and profit trends

# \- Top-performing products

# \- Key business metrics that can support decision-making

#
